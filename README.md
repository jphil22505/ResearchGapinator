# PaperTrail

An AI-powered research gap discovery and evidence mapping platform.

## Objective

PaperTrail helps university students identify potential research gaps by analysing academic literature.

## Initial Research Domain

Computer Science and Artificial Intelligence / Machine Learning.

## Technology Stack

- Python
- OpenAlex API
- FastAPI
- SQLite
- NLP and LLM-based extraction
- Knowledge Graphs

## Project Status

Currently under development.
